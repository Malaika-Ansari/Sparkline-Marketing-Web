# SEO Data Source & Ground-Truth Policy
**Sparkline Marketing Intelligence & Strategy Platform — Phase 18**

## 1. Ground-Truth Mandate

A pervasive issue across modern SEO software is the presentation of synthetic metrics—such as fabricated "estimated monthly organic visits", simulated "domain authority" scores, and speculative "keyword ranking guarantees"—as though they were factual data.

**Sparkline Marketing rejects synthetic data fabrication.** Our SEO Intelligence & Optimization Suite operates strictly according to the following ground-truth policies:

---

## 2. Specific Data Domain Policies

### 2.1 Keyword Search Volumes & Cost-Per-Click (CPC)
- **Policy**: In the absence of an authenticated third-party provider API (such as Google Ads Keyword Planner, Google Search Console, or an approved enterprise data provider), Sparkline **will never invent numerical search volume numbers or dollar CPC estimates**.
- **Labeling Standard**: All conceptual keyword ideas generated by our semantic research engine or Gemini AI are explicitly badged as `AI-Generated Suggestion`.
- **Strategic Focus**: Recommendations are prioritized based on verified **search intent, semantic alignment, and business model value** rather than speculative search volume counts.

### 2.2 Google Rankings & SERP Position Claims
- **Policy**: Sparkline does not claim to predict, guarantee, or simulate Google search rankings.
- **Reporting Standard**: Historical rank tracking and click-through rates displayed in the SEO Performance module represent **user-logged Search Console performance snapshots** or authenticated Google Search Console API feeds.

### 2.3 Competitor Analysis
- **Policy**: Competitor evaluations inspect **publicly observable HTML elements only**:
  - Live `<title>` tags and meta descriptions.
  - Visible heading structures (`<h1>`, `<h2>`).
  - Observed keyword themes in public copy.
  - Publicly visible content formats (blog, comparison table, landing page).
- **Prohibited Behavior**: Sparkline never claims to know a competitor's private Google Analytics traffic, internal conversion rates, or unverified ad spend.

### 2.4 Backlink Data
- **Policy**: Backlink logs represent verified citations recorded by the growth team or synced from authenticated link repositories.
- **Verification Standard**: Each backlink displays its destination URL, exact anchor text, referring source domain, and rel attribute (`follow`, `nofollow`, `ugc`, `sponsored`).

## 3. Architecture for Future Authenticated Data Providers

Sparkline’s data models are architected to ingest verified metrics seamlessly when an API key is connected:

```typescript
export interface VerifiedSEOProviderMetrics {
  searchVolume?: number;
  cpc?: number;
  difficulty?: number;
  providerName: 'Google Search Console' | 'Google Ads' | 'Ahrefs API' | 'Semrush API';
  retrievedDate: string;
}
```

When an external provider is connected:
1. Metrics display the provider’s badge and retrieval timestamp.
2. The user is informed of the cache expiration date.
3. If an API call fails or expires, the system gracefully falls back to semantic intent mapping without inventing values.
